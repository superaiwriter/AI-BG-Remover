# Sentinel Journal

## 2025-07-10 - Constraint-based Security Baseline
**Vulnerability:** Lack of secret protection (missing .gitignore and .env templates).
**Learning:** Initial attempt to fix multiple security hygiene issues (policy + gitignore) exceeded the 50-line limit and the "single enhancement" constraint. In restricted environments, security enhancements must be decoupled.
**Prevention:** Prioritize secret leakage prevention as the first layer of defense when establishing a baseline.
