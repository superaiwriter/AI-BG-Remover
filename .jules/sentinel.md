## 2025-07-11 - Establishing Security Baseline
**Vulnerability:** Initial repository lacked basic security hygiene, risking secret exposure and unmonitored vulnerability reports.
**Learning:** New projects often lack basic security protections like .gitignore, SECURITY.md, and .env.example, which can lead to accidental secret leakage and unclear vulnerability reporting processes.
**Prevention:** Always initialize repositories with a standard security baseline including secret leakage prevention and a clear security policy.
