## 2025-07-03 - [Security Baseline]
**Vulnerability:** Initial repository lacked basic security hygiene, risking secret exposure and unmonitored vulnerability reports.
**Learning:** Establishing a security baseline early (gitignore, security policy, env templates) is crucial for defense-in-depth, even before the first line of app code is written.
**Prevention:** Always initialize new projects with a standard security configuration to prevent accidental leakage of local environment state and credentials.
