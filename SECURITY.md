# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Email us**: Send an email to security@example.com with the details of the vulnerability.
2. **Details to include**:
   - Description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact of the vulnerability.
3. **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
4. **Resolution**: We will work to resolve the issue as quickly as possible and keep you updated on our progress.

Please do not disclose the vulnerability publicly until we have had a chance to address it.

Thank you for helping keep this project secure!
