# Security Policy

## Supported Versions

Currently, only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as soon as possible.

Please do **not** report security vulnerabilities via public GitHub issues.

Instead, please send an email to security@example.com.

### What to include in your report:

-   A description of the vulnerability.
-   Steps to reproduce the issue.
-   The potential impact of the vulnerability.
-   Any suggested fixes or mitigations.

### Our process:

1.  **Acknowledgement:** We will acknowledge your report within 48 hours.
2.  **Validation:** We will work to validate the vulnerability and determine its severity.
3.  **Fix:** We will develop a fix and test it thoroughly.
4.  **Disclosure:** We will coordinate a disclosure timeline once the fix is ready.

Thank you for helping keep this project secure!
